\begin{abstract}
Fully sequential analysis tests the data after every
response. Group sequential methods with few looks
replaced it from the late 1970s. This paper asks
whether modern computing and the alpha spending
function justify more frequent monitoring. We compare a
fixed design with O'Brien-Fleming spending designs
using 3 to 50 looks or one per pair. The trial has two
arms and a normal outcome with known variance. By exact
calculation, type I error stays at 0.05 for every
number of looks. In a trial sized for 90 percent power,
one look per pair cuts expected sample size by about a
third. Power falls by about 1.5 percentage points.
Twenty looks capture most of this gain. A response lag
reduces the gain. These results largely agree with
known theory. We suggest about 20 looks as a default
for trials with fast responses.
\end{abstract}

\section{Introduction}\label{introduction}

We begin with one of the oldest problems in sequential
statistics. The problem is how to monitor accumulating
data in a clinical trial, and possibly stop the study
before all planned observations have been collected.\textsuperscript{\citeproc{ref-wald1945sequential}{1}} laid the theoretical foundations.
He introduced the sequential probability ratio test
(SPRT) for testing simple hypotheses under continuous
monitoring. Wald showed that the SPRT is optimal in a
precise sense. Among all tests with the same type I and
type II error rates, it minimizes the expected sample
size\textsuperscript{\citeproc{ref-wald1947sequential}{2}}. This result established a
strong intellectual framework. That is, suppose one can
evaluate the accumulating evidence after every single
observation. Then one can, on average, reach a decision
with fewer subjects than any fixed-sample design would
require.

\subsection{Armitage and Sequential Medical Trials}\label{armitage-and-sequential-medical-trials}

\textsuperscript{\citeproc{ref-armitage1975sequential}{3}} championed the application of
Wald's ideas to medical research. His monograph
\emph{Sequential Medical Trials} became the standard
reference for what we now call fully sequential
analysis. In Armitage's framework, the test statistic
is recalculated each time a new patient response
becomes available. The result is then compared against
pre-specified stopping boundaries. If the statistic
crosses the upper boundary, the trial stops with
evidence of a treatment effect. If it crosses the lower
boundary, the trial stops for futility or for evidence
of harm. Armitage also developed restricted sequential
procedures that imposed a maximum sample size. This
addressed a theoretical concern about the open SPRT.
Under certain parameter configurations, the open SPRT
could run indefinitely\textsuperscript{\citeproc{ref-armitage1969sequential}{4}}.

The appeal of this approach is easy to see. With
continuous evaluation of the evidence, one could expect
to enroll substantially fewer patients than a
fixed-sample design when the true treatment effect was
large.\textsuperscript{\citeproc{ref-armitage1991interim}{5}} later reflected on the
evolution of interim analysis methods. He noted both
the strengths and the practical limitations that
eventually led the field toward other approaches.

\subsection{The group sequential revolution}\label{the-group-sequential-revolution}

Fully sequential procedures are theoretically elegant.
However, practical considerations drove a fundamental
shift in how clinical trials were monitored.\textsuperscript{\citeproc{ref-pocock1977group}{6}} proposed the group sequential
approach. In this approach the test statistic is
evaluated only at a small number of pre-planned interim
analyses. Each analysis is conducted after a group of
patients has completed follow-up. Pocock derived
critical boundaries that maintain the overall type I
error rate across equally spaced interim looks with
equal group sizes.

Shortly thereafter,\textsuperscript{\citeproc{ref-obrien1979multiple}{7}} introduced
another boundary shape, now universally known as the
O'Brien-Fleming boundary. The Pocock boundary uses a
constant critical value at each analysis. The
O'Brien-Fleming boundary, by contrast, is extremely
conservative at early interim analyses. It approaches
the fixed-sample critical value only at the final
analysis. This property proved highly attractive in
practice. It preserves nearly all of the power of a
fixed-sample design. At the same time, it still permits
early termination when the treatment effect is
overwhelming.

\textsuperscript{\citeproc{ref-fleming1984designs}{8}} further refined the group
sequential framework with additional designs for group
sequential tests.\textsuperscript{\citeproc{ref-wang1987approximately}{9}} then gave a
one-parameter family of boundaries. The family includes
the Pocock and O'Brien-Fleming shapes as special cases
and spans the range between them.

\subsection{The alpha spending function}\label{the-alpha-spending-function}

A major theoretical advance ultimately bridged the gap
between fully sequential and group sequential methods.
This was the alpha spending function introduced by\textsuperscript{\citeproc{ref-lan1983discrete}{10}}. The spending function approach does
not require the number and timing of interim analyses
to be fixed in advance. It specifies only the rate at
which type I error probability is `spent' as a function
of the information fraction. This permits considerable
flexibility. The number of interim analyses, the timing
of each, and even the group sizes can vary without
inflating the type I error rate. The condition is that
the cumulative alpha spent at each analysis respects
the pre-specified spending function.

\textsuperscript{\citeproc{ref-demetsInterimAnalysisAlpha1994}{11}} provided a comprehensive
exposition of the approach. They showed that Pocock-
and O'Brien-Fleming-type boundaries can be recovered as
special cases of particular spending functions. The
Hwang-Shih-De Cani family of spending functions\textsuperscript{\citeproc{ref-hwang1990group}{12}} offered a further parameterization.
It covers a wide range of boundary shapes. These
include shapes more conservative than O'Brien-Fleming
and shapes more aggressive than Pocock.

The spending function framework is directly relevant to
the fully sequential paradigm. In principle, it can
accommodate an arbitrarily large number of analyses,
including the limiting case of continuous monitoring.\textsuperscript{\citeproc{ref-betensky1998continuous}{13}} explicitly showed how to
construct a continuous stopping boundary from an alpha
spending function. This provided the mathematical
machinery needed to implement fully sequential
monitoring within the modern spending function
framework. This result is central to our reassessment.
It implies that fully sequential analysis with group
size one is not a fundamentally different methodology
from group sequential analysis. Rather, it is the
limiting case of the same framework.

\subsection{The triangular test}\label{the-triangular-test}

\textsuperscript{\citeproc{ref-whitehead1983triangular}{14}} pursued a parallel line of
development. They proposed the triangular test. This
sequential procedure allows stopping for both efficacy
and futility. It maintains approximately optimal
expected sample size properties.\textsuperscript{\citeproc{ref-whitehead1997design}{15}}
extended this into a comprehensive methodology for
sequential clinical trials. This included the double
triangular test for two-sided alternatives. The
triangular test occupies a conceptual middle ground
between fully sequential and group sequential methods.
It permits frequent interim analyses, though not
necessarily after every observation. It also provides
natural boundaries for both directions of early
stopping.

\textsuperscript{\citeproc{ref-armitage2014evolution}{16}} gave a historical account of how
methods for deciding when a trial should stop
recruiting have evolved.

\subsection{Why the field moved to group sequential methods}\label{why-the-field-moved-to-group-sequential-methods}

Several practical considerations explain why group
sequential methods eclipsed the fully sequential
approach. This happened despite the latter's
theoretical efficiency advantages. We note that the
reasons are largely logistical rather than statistical:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  Multi-center trials. Clinical trials grew larger
  and were conducted across multiple sites. It then
  became logistically infeasible to update and
  evaluate the test statistic after every individual
  response. Data had to be collected, cleaned, and
  transmitted to a central coordinating center. That
  process naturally imposed grouping.
\item
  Delayed outcomes. The primary endpoint may require
  weeks or months to ascertain (e.g., progression-free
  survival, functional recovery scores). In that case,
  continuous monitoring after each observation is not
  meaningful. Many previously enrolled patients have
  not yet contributed their outcomes.
\item
  Data monitoring committees. Independent Data Safety
  Monitoring Boards (DSMBs) were established as a
  governance mechanism. They introduced a deliberative
  human element. That element requires scheduled
  meetings, not continuous algorithmic monitoring.
\item
  Computational limitations. In the 1970s and 1980s,
  the computational burden of continuously updating
  boundaries and test statistics was non-trivial.
  Modern computing has largely eliminated this
  constraint.
\item
  Regulatory practice. Regulatory agencies became
  accustomed to reviewing trial designs with a small
  number of planned interim analyses. Guidance
  documents reflected this norm.
\end{enumerate}

\subsection{Comparison of fully sequential and group sequential approaches}\label{comparison-of-fully-sequential-and-group-sequential-approaches}

\textsuperscript{\citeproc{ref-sebille2000comparison}{17}} conducted a direct comparison of
four sequential methods. These were the SPRT, the
triangular test, and one-parameter boundaries alongside
Pocock and O'Brien-Fleming group sequential boundaries.
They evaluated operating characteristics including
expected sample size, power, and type I error control.\textsuperscript{\citeproc{ref-sebille2003sequential}{18}} provided a more comprehensive
review contrasting strictly sequential methods with
group sequential designs. They concluded that the
practical complexity of fully sequential methods
partially offsets their theoretical sample size
savings.

\textsuperscript{\citeproc{ref-lai1980sequential}{19}} established that certain sequential
stopping rules are asymptotically optimal from both
Bayesian and frequentist perspectives. This provides
theoretical justification for continuous monitoring
when it is feasible.\textsuperscript{\citeproc{ref-xiong1996continuous}{20}} extended the
sequential conditional probability ratio test (SCPRT)
framework. The extension accommodates both continuous
and group sequential monitoring within a unified
approach. This further shows that the boundary between
these paradigms is more fluid than the dichotomy might
suggest.

\subsection{Post-estimation challenges}\label{post-estimation-challenges}

Sequential analysis has a well-known complication,
whether it is fully sequential or group sequential.
Naive maximum likelihood estimates obtained at the
stopping time are biased.\textsuperscript{\citeproc{ref-emersonParameterEstimationFollowing1990}{21}} investigated
parameter estimation following group sequential tests.
They proposed orderings of the sample space that yield
improved point estimates and confidence intervals.
These estimation challenges are shared by both
paradigms. We note, however, that the bias can be more
pronounced under continuous monitoring. The reason is
that the test statistic is evaluated at a
boundary-crossing point that is, by construction,
extreme.

\subsection{Modern extensions: longitudinal and adaptive designs}\label{modern-extensions-longitudinal-and-adaptive-designs}

Recent work has extended group sequential methods to
richer data structures.\textsuperscript{\citeproc{ref-jeffriesLongitudinalClinicalTrials2015}{22}} considered
longitudinal trials with adaptive choice of follow-up
time.\textsuperscript{\citeproc{ref-jeffriesDetectingTreatmentDifferences2018}{23}}
incorporated covariate adjustment in group sequential
longitudinal studies.\textsuperscript{\citeproc{ref-jeffriesEvaluatingTreatmentEffects2023}{24}} further
generalized these methods to multivariate longitudinal
endpoints. These developments are relevant. They show
the continuing evolution of group sequential
methodology toward greater flexibility. They do not,
however, address whether reducing the group size to
one offers additional advantages.

The broader adaptive design literature has focused
primarily on sample size re-estimation, treatment
selection, and enrichment designs. This literature is
codified in\textsuperscript{\citeproc{ref-wassmer2016group}{25}}. It is implemented in
software such as rpact\textsuperscript{\citeproc{ref-wassmer2023rpact}{26}} and gsDesign\textsuperscript{\citeproc{ref-anderson2022gsdesign}{27}}. These adaptations presuppose a
group sequential monitoring structure.

\subsection{Safety surveillance: a revival of continuous monitoring}\label{safety-surveillance-a-revival-of-continuous-monitoring}

Post-market safety surveillance is one domain in which
fully sequential, or near-fully sequential, monitoring
has seen a genuine revival.\textsuperscript{\citeproc{ref-silva2015continuous}{28}}
compared continuous and group sequential analysis for
post-market drug and vaccine safety surveillance. They
showed that for any group sequential design there is a
continuous design that is uniformly better. They
concluded that surveillance should test each time new
data arrive. Their setting is a Poisson model with a
flat boundary on the log likelihood ratio scale. In
this setting, the
practical constraints that drove the original move to
group sequential methods are less binding. Data are
collected electronically in real time. The `outcome'
(an adverse event) is typically ascertained quickly.
The monitoring is algorithmic rather than
committee-based. This application shows that the fully
sequential paradigm retains practical value in some
settings. These are settings where its original
advantages, minimal expected sample size and rapid
detection, can be realized.

\subsection{Present study}\label{present-study}

We examine whether the fully sequential approach merits
reassessment for contemporary clinical trials beyond
safety surveillance. In this approach the stopping
boundary is evaluated after each new response. In our
two-arm simulation this means one look per enrolled
treated-control pair. The question is motivated by
three developments since the 1970s:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Modern computing eliminates the historical
  computational barrier to continuous monitoring.
\item
  The alpha spending function framework\textsuperscript{\citeproc{ref-lan1983discrete}{10},\citeproc{ref-demetsInterimAnalysisAlpha1994}{11}}
  provides a rigorous theoretical foundation for
  continuous monitoring that controls type I error.
\item
  Electronic data capture and real-time data
  pipelines have reduced the logistical barriers
  to rapid data aggregation.
\end{enumerate}

We investigate the operating characteristics of a
fully sequential design (group size one, alpha
spending function boundaries). We compare it with
standard group sequential designs with three to five
interim analyses. We focus on expected sample size,
power, and the practical trade-offs involved. The
main-body comparison (fixed versus K = 3, 5 versus
fully sequential) largely reproduces a known result.
That result was already established by\textsuperscript{\citeproc{ref-sebille2000comparison}{17}},\textsuperscript{\citeproc{ref-sebille2003sequential}{18}}, and\textsuperscript{\citeproc{ref-jennison2000group}{29}} (Chapter 7). It states that most of
the efficiency gain of sequential monitoring is
captured by a handful of looks. The Appendix extends
the comparison to a grid of K between 5 and N. It
shows where the returns in expected sample size
diminish. This pattern is, at least in part, already
known from the optimal-design and textbook literature\textsuperscript{\citeproc{ref-jennison2000group}{29},\citeproc{ref-eales1992improved}{30}}. What we add is
an exact calculation of power, expected sample size,
and maximum-sample-size inflation over that grid. We
also add a simple delayed-response calculation. On that
basis we discuss high-frequency monitoring (K = 20 to
50) as a practical middle ground. Readers mainly
interested in that contribution can proceed directly
to the Appendix. They may do so after the Methods and
headline Results below.

\section{Methods}\label{methods}

\subsection{ADEMP structure}\label{ademp-structure}

Following Morris, White, and Crowther\textsuperscript{\citeproc{ref-morris2019using}{31}}, we report the simulation under the
ADEMP framework.

\begin{itemize}
\tightlist
\item
  Aims. Compare the operating characteristics of fixed-sample,
  group-sequential (K = 3, 5), and fully sequential designs. All
  use Lan-DeMets O'Brien-Fleming spending, across a range of true
  treatment effects.
\item
  Data-generating mechanism. Two-arm continuous outcome with
  known variance. We use \(n_{\max} = 200\) per arm in the main
  grid. We use \(n_{\max} = 85\) per arm in the power-calibrated
  sensitivity scenario (Results).
\item
  Estimands. (i) The binary rejection decision at
  \(\alpha = 0.05\); (ii) expected sample size at stopping; (iii) the
  naive MLE at stop, which exhibits early-stopping bias.
\item
  Methods. Fixed design; group-sequential with K = 3, 5; fully
  sequential (K = n\_max) in the main grid (Results). The finer
  K = 3, 5, 10, 20, 50, n\_max grid is run only at \(\delta = 0.5\).
  It is run in both the appendix's overpowered scenario
  (\(n_{\max} = 200\)) and its power-calibrated companion
  (\(n_{\max} = 85\)).
\item
  Performance measures. Rejection rate, mean and median N at
  stop, naive bias, and RMSE of the naive MLE. Each is reported
  with its Monte Carlo SE per Morris Table 6. For rejection-rate
  MCSE \(\leq 1.1\) pp at \(p = 0.5\), \(n_{\mathrm{rep}} \geq 2{,}066\);
  \(n_{\mathrm{rep}} = 2{,}000\) gives MCSE \(\approx 1.12\) pp.
  Differences in power between designs are often smaller than
  this. We therefore also compute rejection probabilities and
  expected sample sizes exactly, by numerical integration
  (Section `Exact calculation' below). The simulation is kept
  for the naive estimator's bias and RMSE, which the exact
  calculation does not give.
\end{itemize}

\subsection{Design framework}\label{design-framework}

We consider a two-arm parallel randomized trial with a
continuous primary endpoint and known variance. Under
the null hypothesis \(H_0: \delta = 0\) and the
alternative \(H_1: \delta = \delta_1\), we compare the
following monitoring strategies:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Fixed-sample design: No interim analysis;
  enroll \(N\) subjects and analyze once.
\item
  Group sequential design (K = 3): Three equally
  spaced interim analyses with O'Brien-Fleming-type
  alpha spending.
\item
  Group sequential design (K = 5): Five equally
  spaced interim analyses with O'Brien-Fleming-type
  alpha spending.
\item
  Fully sequential design (K = N): Evaluate the
  boundary after each enrolled treated-control pair,
  that is, at \(n = 1, 2, \ldots, N\) pairs. Use the
  Lan-DeMets alpha spending function corresponding
  to O'Brien-Fleming boundaries.
\end{enumerate}

For K \textless{} N the looks fall at \(n_j = \mathrm{round}(jN/K)\)
pairs, \(j = 1, \ldots, K\). The boundaries are computed
at the realized information fractions \(n_j / N\). They
are therefore matched to the looks at which they are
applied. Rejection is two-sided, so a trial stops when
\(|Z|\) crosses the boundary in either direction. `Power'
therefore includes rejections in the wrong direction.
The exact probability of such a rejection is at most
0.0007
for every design and every \(\delta \geq 0.2\) studied
here.

\subsection{Alpha spending function}\label{alpha-spending-function}

For all group sequential and fully sequential designs,
we use the Lan-DeMets spending function that
approximates the O'Brien-Fleming boundary. It is
applied to each tail separately at the one-sided level
\(\alpha/2 = 0.025\). In symbols, the alpha spent in each
tail by information fraction \(t\) is

\[\alpha_1^*(t) = 2 - 2\Phi\left(\frac{z_{\alpha/4}}{\sqrt{t}}\right),\]

where \(t \in (0, 1]\) is the information fraction,
\(\Phi\) is the standard normal CDF, and
\(z_{\alpha/4} = z_{0.0125} \approx 2.24\). The total
two-sided spending is \(2\alpha_1^*(t)\), which equals
\(\alpha = 0.05\) at \(t = 1\). This is the function that
\texttt{gsDesign(test.type\ =\ 2,\ alpha\ =\ 0.025,\ sfu\ =\ sfLDOF)}
uses\textsuperscript{\citeproc{ref-anderson2022gsdesign}{27}}, and all results reflect
it. Some sources write the two-sided O'Brien-Fleming
spending function instead as
\(2 - 2\Phi(z_{\alpha/2}/\sqrt{t})\). The two agree at
\(t = 1\) but not earlier. At \(t = 0.5\), for example, our
function spends
0.0031
in total, against
0.0056
for the two-sided form. Either function spends little
alpha early in the trial. Most of the spending comes
near the end, which is consistent with the
O'Brien-Fleming philosophy.

\subsection{Simulation procedure}\label{simulation-procedure}

We evaluate the operating characteristics of each design
by Monte Carlo simulation:

\begin{itemize}
\tightlist
\item
  True effect sizes: \(\delta \in \{0, 0.2, 0.5, 0.8\}\)

\subsubsection{Exact calculation}\label{exact-calculation}

The rejection probability and expected sample size of
each design can be computed without simulation. We use
the recursive numerical integration of\textsuperscript{\citeproc{ref-jennison2000group}{29}}, as implemented in
gsDesign. After \(n\) pairs the two-sample \(z\)-statistic
has mean \(\delta\sqrt{n/2}\) for unit variance. We pass
the same look schedule and the same boundaries as the
simulation. The calculation is deterministic and has
no Monte Carlo error. We checked its numerical accuracy
by halving the integration grid. Rejection
probabilities changed by less than \(10^{-5}\) and
expected sample sizes by less than 0.001 pairs. Most
simulated rejection rates and mean sample sizes lie
within two Monte Carlo SEs of the exact values. Two
simulated mean sample sizes lie three to four SEs away
(K = 5 at \(\delta = 0.2\), and the fully sequential
design at \(N_{\max} = 85\)). Where the two disagree we
treat the exact values as authoritative. The same
calculation gives the maximum-sample-size inflation
needed to hold power at 90 percent for each K. It also
gives expected enrollment when some subjects are in the
pipeline at each look (see the Appendix).

\section{Discussion}\label{discussion}

We shall interpret the results in the context of both
the theoretical and the practical dimensions of
clinical trial monitoring.

From a purely statistical perspective, the fully
sequential design (group size one) is the limiting case
of the group sequential framework. As predicted by the
classical theory\textsuperscript{\citeproc{ref-wald1947sequential}{2},\citeproc{ref-armitage1975sequential}{3}}, it
achieves the lowest expected sample size when the true
treatment effect is large. The marginal gain from
moving from five interim analyses to continuous
monitoring is, however, modest. This is consistent with
a well-known result\textsuperscript{\citeproc{ref-jennison2000group}{29(chap7)}}. That is, most of the efficiency benefit of
sequential monitoring is captured by the first few
interim analyses.

The alpha spending function framework\textsuperscript{\citeproc{ref-lan1983discrete}{10},\citeproc{ref-demetsInterimAnalysisAlpha1994}{11}}
provides the theoretical foundation that makes fully
sequential monitoring rigorous within the modern
inferential framework.\textsuperscript{\citeproc{ref-betensky1998continuous}{13}} showed
that continuous stopping boundaries can be constructed
directly from spending functions. The exact calculation
shows that type I error is held at the nominal
\(\alpha = 0.05\) for every K we studied. This includes
one look per pair. The simulated rates at
\(n_{\mathrm{rep}} = 20{,}000\) lie within two Monte Carlo
SEs of nominal, which is consistent with this. We have
not examined designs whose look times are not fixed in
advance.

The designs compared here stop only on rejection of the
null. No futility (beta-spending) boundary is
implemented. A trial that fails to cross the upper
boundary therefore continues to \(N_{\max}\).
Consequently, under \(H_0\) the exact expected sample
size is
197.8
to 200 pairs for every design at \(N_{\max} = 200\). The simulation therefore shows no
expected sample size benefit under the null. Yet the
Introduction motivates fully sequential monitoring
partly through Armitage's lower futility and harm
boundary. In addition, the appendix's architecture
proposal recommends conditional-power futility alerts.
We note that the ASN savings reported throughout this
report are therefore savings from efficacy-only
stopping under a true, nonzero treatment effect. They
say nothing about the sample size benefit, if any, of
stopping early for futility. That would require adding
a beta-spending boundary, and it is left for future
work (see Future research). Readers should read every
claim of sample size `savings' in this report as
conditional on that scope.

Every simulated look is evaluated after a
treated-control pair (K = 200 corresponds to 200 pairs,
400 subjects, at the main-grid \(N_{\max}\)). A literal
reading of `fully sequential' (group size one,
following one observation at a time) might suggest a
look after each individual response. That is not what
is simulated here. We retain the paired framing
throughout. The two-arm normal DGM pairs enrollment
across arms by construction. The qualitative comparison
to group sequential designs with K = 3 or K = 5 looks
is unaffected. However, the label `fully sequential'
here means `one look per enrolled pair,' not `one look
per observation.'

The practical arguments against fully sequential
monitoring remain valid for most large confirmatory
trials. These arguments are multi-center logistics,
delayed outcomes, and DSMB governance. On the other
hand, several evolving features of contemporary
clinical trial practice may narrow the practical gap:

\begin{itemize}
\tightlist
\item
  Electronic data capture systems increasingly
  support near-real-time data availability.
\item
  Decentralized trial designs reduce the data
  transmission delays inherent in multi-site studies.
\item
  Rapidly ascertained endpoints (e.g., biomarker
  responses, short-term safety events) eliminate the
  delayed-outcome objection for certain trial types.
\item
  Algorithmic monitoring can complement, rather than
  replace, DSMB review. A continuous monitoring
  system could trigger an ad hoc DSMB meeting when
  evidence crosses a threshold.
\end{itemize}

Continuous sequential monitoring has been revived in
post-market safety surveillance\textsuperscript{\citeproc{ref-silva2015continuous}{28},\citeproc{ref-kulldorff2011maximized}{32}}. This
revival shows that the approach is already viable in
settings that share some of these characteristics.

Delayed response is, in our view, the most important
of these practical barriers.\textsuperscript{\citeproc{ref-hampson2013delayed}{33}} showed
that the reduction in expected sample size from a group
sequential test shrinks when there is a delay in
response. The reason is that subjects already treated
but not yet observed are in the pipeline when the trial
stops. Our main simulation assumes instantaneous
response. In the Appendix we add a simple pipeline
calculation for the power-calibrated scenario. It shows
the same effect for every K, including fully sequential
monitoring. Whether the same logic extends to
confirmatory efficacy trials remains an open question.
It appears to depend on the specific endpoint,
timeline, and regulatory context.

The comparison of sequential approaches by\textsuperscript{\citeproc{ref-sebille2000comparison}{17}} and\textsuperscript{\citeproc{ref-sebille2003sequential}{18}}
supports a conclusion about how to choose between fully
sequential and group sequential monitoring. The choice
is driven more by practical logistics than by
statistical efficiency. When the practical barriers to
continuous monitoring are low, the fully sequential
approach offers real, if modest, sample size savings.
On the other hand, when those barriers are high, the
group sequential approach sacrifices little efficiency.
In exchange, it gains substantial operational
simplicity.

\subsection{Position relative to anytime-valid inference}\label{position-relative-to-anytime-valid-inference}

The spending-function approach evaluated here is not
the only contemporary route to continuous monitoring
with error control. Since roughly 2011, a distinct
literature on anytime-valid (also called always-valid)
inference has addressed the same problem. The problem
is valid inference at arbitrary, possibly
data-dependent stopping times. This literature starts
from a different point, and it is deployed at
production scale in industrial A/B testing\textsuperscript{\citeproc{ref-johari2017peeking}{34}}. Confidence sequences\textsuperscript{\citeproc{ref-robbins1970statistical}{35},\citeproc{ref-howard2021time}{36}} provide
intervals that are simultaneously valid at every sample
size. A user may therefore stop for any reason without
inflating type I error. This includes looking at every
new observation. E-values and e-processes generalize
this to a broader game-theoretic statistics framework\textsuperscript{\citeproc{ref-ramdas2023game}{37}}. The maximized sequential probability
ratio test of Kulldorff and colleagues\textsuperscript{\citeproc{ref-kulldorff2011maximized}{32}} is the seminal
continuous-monitoring method for drug and vaccine
safety surveillance. It predates the comparison of
continuous and group sequential surveillance cited
earlier\textsuperscript{\citeproc{ref-silva2015continuous}{28}}. The
classical monitoring literature this report draws on is
thoroughly synthesized in\textsuperscript{\citeproc{ref-proschan2006statistical}{38}}. The
repeated confidence interval approach of\textsuperscript{\citeproc{ref-jennison1989interim}{39}} is the group sequential analogue
of a confidence sequence. It is referenced without
citation in the appendix's software architecture
proposal.

These methods differ from the Lan-DeMets alpha-spending
construction used throughout this report in two main
ways. The first is how they are derived:
test-martingale or confidence-sequence arguments versus
information-fraction spending functions. The second is
their typical use case. That is, continuous, often
unbounded monitoring in digital experimentation versus
a fixed-\(N_{\max}\), discretely monitored clinical
trial. We do not implement an mSPRT or
confidence-sequence comparator in the simulation
reported here. A head-to-head comparison would be a
natural extension, and it is listed under Future
research. It would compare expected sample size and
naive-estimator bias between a K = 20 to 50
spending-function design and a comparably tuned
confidence sequence. Absent that comparison, we do not
claim that the spending-function approach dominates
anytime-valid alternatives. We claim only that it
remains the more familiar framework for regulated
confirmatory trials. We also suggest that the
high-frequency monitoring (K = 20 to 50) direction
proposed in the appendix is one practical way to narrow
a gap. That gap lies between the K = 3-5 convention and
the anytime-valid literature that most trialists do not
yet use.

\subsection{Limitations}\label{limitations}

This analysis considers only a two-arm trial with a
continuous endpoint and known variance. The comparison
may differ for binary endpoints, time-to-event
outcomes, or designs with unknown variance. The
simulation uses a fixed maximum sample size. In
practice, the maximum may itself be adapted. The
post-estimation bias issue\textsuperscript{\citeproc{ref-emersonParameterEstimationFollowing1990}{21}} is
acknowledged but not directly evaluated here. No
futility (beta-spending) boundary is implemented. All
reported ASN savings are therefore efficacy-only-stopping
savings (see Discussion). In the main simulation grid,
each design-by-effect-size cell draws independent
normal outcome data. It does not reuse a common
random-number stream across designs. Specifically,
\texttt{run\_simulation()} in \texttt{analysis/scripts/sim\_study.R}
calls \texttt{simulate\_one\_trial()} independently for every
design. Cross-design contrasts at a fixed effect size
are therefore somewhat noisier than a
common-random-numbers design would produce. Each
design's own MCSE is, however, correctly computed from
its own replications. For power, type I error, and
expected sample size, the exact calculation removes
this concern. It remains for the naive bias, which we
estimate only by simulation. The delayed-response
calculation in the Appendix uses a fixed pipeline
length. It has no accrual model and no futility
boundary. Finally, the main-grid comparison
at \(N_{\max} = 200\) is overpowered for
\(\delta \geq 0.5\). We address this with the
power-calibrated sensitivity scenario in Results.
The simulated K-grid in the Appendix, which also gives
the naive bias, is run only at \(\delta = 0.5\). The
exact calculation covers every K at
\(\delta = 0, 0.2, 0.5\), and \(0.8\) (Table
\ref{tab:exact-table}).

\section{Future research}\label{future-research}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  Extension to time-to-event endpoints. The fully
  sequential paradigm is naturally suited to
  event-driven analyses. The connection between
  continuous monitoring and calendar-time spending
  functions\textsuperscript{\citeproc{ref-lan1989group}{40}} warrants
  formal evaluation in the survival setting.
\item
  Integration with adaptive sample size
  re-estimation. Continuous monitoring could be
  combined with unblinded sample size re-estimation\textsuperscript{\citeproc{ref-wassmer2016group}{25}}. The resulting designs could
  adapt both the monitoring frequency and the
  maximum sample size as data accumulate.
\item
  Bayesian continuous monitoring. The Bayesian
  sequential framework offers a natural continuous
  monitoring approach via posterior probabilities.
  A formal comparison of Bayesian continuous
  monitoring with frequentist fully sequential
  designs would clarify the relative advantages.
\item
  Software development. Both gsDesign\textsuperscript{\citeproc{ref-anderson2022gsdesign}{27}} and rpact\textsuperscript{\citeproc{ref-wassmer2023rpact}{26}} support many interim analyses.
  However, dedicated tools for fully sequential
  (K = N) design would facilitate practical adoption.
  Such tools would provide spending function
  boundaries and bias-adjusted estimation.
\item
  Regulatory considerations. Engagement with
  regulatory agencies on the acceptability of fully
  sequential designs is a necessary step before
  broader adoption. This applies particularly to
  trials with rapidly ascertained endpoints.
\item
  Post-estimation methods. Bias-corrected estimators
  and confidence intervals specifically tailored to
  the fully sequential setting need development and
  evaluation. This work would build on Emerson and
  Fleming\textsuperscript{\citeproc{ref-emersonParameterEstimationFollowing1990}{21}}.
\item
  Decentralized trials. The growing use of
  decentralized trial platforms with real-time data
  capture creates a natural testbed. That testbed
  could be used to evaluate fully sequential
  monitoring in practice.
\item
  Comparison against anytime-valid inference. A
  head-to-head simulation would compare the
  spending-function designs evaluated here with an
  anytime-valid procedure. The comparator would be a
  mixture sequential probability ratio test or a
  confidence-sequence procedure\textsuperscript{\citeproc{ref-robbins1970statistical}{35}--\citeproc{ref-ramdas2023game}{37}}. The designs would be matched on
  type I error and power. Such a study would establish
  whether the appendix's high-frequency
  spending-function designs remain competitive with
  the anytime-valid literature on ASN and estimator
  bias.
\item
  Futility stopping. Add a beta-spending futility
  boundary (e.g., \texttt{gsDesign} \texttt{test.type\ =\ 4}) to each
  design. Then re-evaluate ASN under the null and
  under small effect sizes. The efficacy-only designs
  evaluated in this report do not capture these
  settings.
\end{enumerate}

\section{Appendix: High-frequency monitoring as a practical middle ground}\label{appendix-high-frequency-monitoring-as-a-practical-middle-ground}

\subsection{Motivation}\label{motivation}

The main body of this report compares fully sequential
monitoring (K = N) with the standard group sequential
paradigm (K = 3 to 5). The simulation
results and the historical literature converge on the
same conclusion. The statistical efficiency gains from
continuous monitoring are real but modest. The
practical barriers, on the other hand, remain
substantial. This framing,
however, presents a false dichotomy. The alpha spending
function framework imposes no constraint on K. The
question is not whether to use K = 5 or K = N. Rather,
what value of K captures most of the efficiency benefit
while remaining operationally tractable?

We propose that the most productive direction for
sequential analysis in 2026 is not a revival of the
fully sequential paradigm per se. Rather, it is the
development of high-frequency monitoring designs with K
in the range of 20 to 50. We see this as resting on
three pillars. The first is software that handles
large K without numerical instability. The second is
bias-corrected estimation tailored to the
high-frequency setting. The third is automated alerting
systems that translate continuous statistical
monitoring into actionable triggers for human review.

The main simulation assumes that each response is
observed at once. In practice some subjects have been
enrolled but not yet observed at each interim look.\textsuperscript{\citeproc{ref-hampson2013delayed}{33}} call these `pipeline' subjects.
When the trial stops, they have already been enrolled.
We model this in the simplest way. At each interim look
a fixed number of further pairs, \(p\), has been
enrolled, up to \(N_{\max}\). The decision still uses only
the observed pairs, so power and type I error do not
change. Expected enrollment does change. Table
\ref{tab:pipeline-table} gives it for \(p\) = 0, 5, 10,
and 20 pairs. These values are illustrative. For
example, \(p = 10\) would correspond to a one-month
response lag at an accrual rate of 10 pairs per month.

The pipeline reduces the savings of every sequential
design. With no pipeline, K = 20 reduces expected
enrollment by
31.6 percent relative to
the fixed design. With a pipeline of 10 pairs the
reduction is 21.8
percent, and with 20 pairs it is
13.2 percent. The
advantage of K = 20 over K = 5 also shrinks, from
6.0
to
4.0
percentage points. This is the effect that\textsuperscript{\citeproc{ref-hampson2013delayed}{33}} describe. Our calculation has no
accrual model and no futility boundary. It also does
not use the pipeline data at the final analysis in the
way their designs do. It should be read as a rough
indication of how quickly the gains from frequent
looks erode as the response lag grows.

\subsection{Bias under high-frequency monitoring}\label{bias-under-high-frequency-monitoring}

\begin{figure}

{\centering \includegraphics[width=0.9\linewidth]{report_files/figure-latex/hf-bias-plot-1} 

}

\caption{Simulated bias of the naive MLE at the stopping time as a function of K (delta = 0.5, n-max = 200). The bias is small in absolute terms. It dips at K = 5 and rises from K = 10 onward. The dip is within Monte Carlo noise (see MCSE(Bias) in the table above).}\label{fig:hf-bias-plot}
\end{figure}

A well-known consequence of optional stopping is that
the naive maximum likelihood estimate at the stopping
time is biased away from the null\textsuperscript{\citeproc{ref-emersonParameterEstimationFollowing1990}{21},\citeproc{ref-whitehead1986bias}{41}}.
At \(N_{\max} = 200\) the simulated bias is
0.035
at K = 3 and
0.031
at K = 5. It then rises steadily, from
0.034
at K = 10 to
0.045
at K = 200. The MCSE of each value is about
0.003,
so the dip at K = 5 is within Monte Carlo noise. The
rise from K = 10 onward has a plausible explanation.
More frequent monitoring gives the test statistic more
chances to cross the boundary at an extreme value. We
have not tested that trend formally. Two
observations, however, temper this concern. First, the
absolute magnitude of the bias remains modest even at
K = 200. Second, the bias is a known and correctable
phenomenon. Several approaches to bias-adjusted
estimation following sequential monitoring have been
developed. These include bias-adjusted maximum
likelihood estimation\textsuperscript{\citeproc{ref-whitehead1986bias}{41}}, median
unbiased estimation based on an ordering of the sample
space\textsuperscript{\citeproc{ref-emersonParameterEstimationFollowing1990}{21}}. The
bias conditional on early stopping has also been
studied\textsuperscript{\citeproc{ref-fan2004conditional}{42}}. Practical
adoption of
high-frequency monitoring will require that these
methods be packaged into accessible software. Otherwise
they will remain the province of methodological
specialists.

\subsection{A software architecture for high-frequency monitoring}\label{a-software-architecture-for-high-frequency-monitoring}

The current generation of group sequential software was
designed for the K = 3 to 5 regime. This generation
includes gsDesign\textsuperscript{\citeproc{ref-anderson2022gsdesign}{27}}, rpact\textsuperscript{\citeproc{ref-wassmer2023rpact}{26}}, and the Lan-DeMets boundary
programs. These tools can technically accommodate
larger K, but they were not optimized for it. We
suggest that a purpose-built system for high-frequency
monitoring would require three components.

\emph{Boundary computation engine.} The spending function
must be evaluated at K = 20 to 50 information
fractions. The corresponding critical boundaries must
then be computed. This uses numerical integration or
recursive application of the multivariate normal
distribution. For moderate K (up to 50), existing
algorithms based on the work of\textsuperscript{\citeproc{ref-jennison2000group}{29}}
scale adequately. For K approaching N, direct
computation becomes prohibitive. In that case the
continuous boundary approximation of\textsuperscript{\citeproc{ref-betensky1998continuous}{13}} should be used instead. A
practical implementation would pre-compute boundaries
for a fine grid of information fractions. It would then
interpolate at the actual analysis times.

\emph{Bias-corrected estimation module.} At each interim
analysis, the system should report the naive test
statistic and p-value. It should also report the
following:

\begin{itemize}
\tightlist
\item
  The median unbiased estimate of the treatment effect.
  It is computed by inverting the stage-wise ordering of
  the sample space.
\item
  A repeated confidence interval that maintains
  simultaneous coverage across all analysis times.
\item
  The conditional power given the data observed so
  far. This would inform DSMB deliberations about
  futility.
\end{itemize}

These quantities are computationally more demanding
than the naive estimates. They are, however, feasible
for K up to 50 with modern hardware.

\emph{Automated alerting layer.} Perhaps the most
consequential practical innovation would be an alerting
system. Such a system decouples statistical monitoring
from DSMB scheduling. In the current paradigm, the DSMB
meets at pre-specified calendar times. The interim
analysis is conducted at that meeting. In a
high-frequency monitoring paradigm, the statistical
comparison would run continuously, or at each new data
lock. The system would generate alerts at three
thresholds:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \emph{Efficacy signal}: the test statistic crosses the
  upper spending function boundary. This triggers an
  expedited DSMB meeting. The DSMB would review the
  unblinded data and consider early termination.
\item
  \emph{Futility signal}: the conditional power falls
  below a pre-specified threshold (e.g., 10 to 20\%).
  This triggers a DSMB review of whether to continue
  enrollment.
\item
  \emph{Safety signal}: a secondary monitoring rule for
  adverse events crosses a safety boundary. This
  triggers immediate safety review, regardless of the
  efficacy analysis schedule.
\end{enumerate}

The DSMB retains full authority over all stopping
decisions. The system merely ensures that evidence is
not accumulating unexamined between scheduled meetings.
This is particularly relevant for trials in which
enrollment is fast relative to the DSMB meeting
schedule. For instance, suppose 50 patients enroll
between quarterly meetings. A group sequential design
with K = 5 may then miss the opportunity to stop the
trial at the statistically optimal time.

\subsection{The diminishing marginal cost of more analyses}\label{the-diminishing-marginal-cost-of-more-analyses}

A natural counterargument to high-frequency monitoring
is that each interim analysis incurs administrative
cost. This cost includes data locks, database
reconciliation, statistical programming, and DSMB
coordination. This is true in the current paradigm, but
it is largely an artifact of it. Suppose the monitoring
system is automated. That is, data are ingested
continuously from electronic data capture, boundaries
are pre-computed, and the test statistic is updated
programmatically. Then we conjecture that the marginal
cost of the 21st analysis would be small. The cost
structure would shift from per-analysis overhead to a
fixed upfront investment in infrastructure. We have
not measured either cost. Consider large trials where
the cost per enrolled patient is high and the potential
savings from early termination are substantial. For
such trials the investment may be worthwhile. A cost
model would be needed to show this.

\subsection{Practical recommendations}\label{practical-recommendations}

In sum, based on the simulation results and the
considerations above, we offer the following concrete
recommendations:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  Consider K = 20 rather than K = 5 when responses
  are observed quickly relative to accrual. The exact
  type I error at K = 20 is
  0.0500, so the
  spending function holds the nominal level. With no
  pipeline, K = 20 lowers expected enrollment at
  \(\delta = 0.5\) by
  6.0
  percentage points more than K = 5 does. With a
  pipeline of 20 pairs the extra gain is
  4.0
  points. How short the response lag must be for K =
  20 to be worthwhile depends on the accrual rate. We
  have not modeled it beyond the illustrative values
  above. We also conjecture, without measurement, that
  the overhead of the extra looks is small if
  monitoring is automated.
\item
  Use the O'Brien-Fleming spending function, and
  inflate the maximum sample size to hold power. At
  high K the O'Brien-Fleming function spends little
  alpha at early analyses. The cost of `looking more
  often' is therefore borne mostly by an increase in
  the maximum sample size. The exact inflation needed
  for 90 percent power is
  2.3 percent
  for K = 5,
  4.4 percent
  for K = 20, and
  5.3 percent
  for K = 200. Without this inflation the sequential
  designs lose a little power, as in Table
  \ref{tab:exact-table}.
\item
  Report bias-corrected estimates at every analysis.
  The naive MLE should never be the sole estimate
  presented to a DSMB. At minimum, report the median
  unbiased estimate and the repeated confidence
  interval alongside the naive values.
\item
  Build the alerting system first. The most impactful
  near-term investment is in software engineering,
  not in novel statistical methodology. The system
  would ingest data, update the test statistic, and
  evaluate it against pre-computed boundaries. It
  would generate structured alerts when thresholds
  are crossed. This system should produce a
  standardized DSMB report at each triggered
  analysis. The report would include the spending
  function status (cumulative alpha spent), the
  bias-corrected estimate, and conditional power. It
  would also include a recommendation on whether a
  DSMB meeting is warranted.
\item
  Treat K as a design parameter to be optimized. Do
  not choose K by convention (the current default of
  3 to 5). Instead, select K by explicitly trading
  off expected sample size savings against
  infrastructure cost. The diminishing-returns curve
  from the simulation provides the empirical basis
  for this trade-off.
\end{enumerate}
